Run analysis only when you intend to

AI analysis can disclose retained report evidence to your configured Azure model deployment and incur charges. Saving or testing settings never runs report analysis. Command-line configuration remains supported.

To regenerate reports with AI, stop the runner first, then use an explicit command:

.\Start-App.ps1 -AnalyzeAgentBehavior
.\Start-App.ps1 -ModelSynthesis

If you started the runner with a custom configuration path, pass the same -ConfigurationPath to these commands.
